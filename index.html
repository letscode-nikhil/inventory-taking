Users, locations, products and storage types are built into this app from your warehouse files. When those files change on production, import the latest copy below — each replaces its data immediately and is remembered on this device.

Update location master list (Excel or CSV)

Columns, no header row: la_id, la_name, loc_id, loc_pos_display_id. Replaces the list of all locations; assignments to locations that no longer exist are removed.

Update users (Excel .xlsx/.xls or CSV)

Excel or CSV with one column: user_name

Update user → location access (Excel .xlsx/.xls or CSV)

Excel or CSV with columns: la_id, la_name, loc_id, loc_pos_display_id, user1 (the assigned-user column — despite its header name it holds each user's own name, e.g. user1/user2/user3)

Update product / storage list (Excel .xlsx/.xls or CSV)

Excel or CSV with columns: prod_code, display_product, storage formatted like Case=1.00, and default_ind Y/N for primary

Update login credentials (Excel .xlsx/.xls or CSV)

Excel/CSV with two columns, no header row: username, password.
